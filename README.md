## About the Project

Flossy is an all-in-one web application that allows users to book appointments with different dentists across the city of Gothenburg. The platform is a distributed systems that allows practicians to integrate the Dentist API into their system in order to log their data into the website's database. This way users can see available offices in the integrated map of Gothenburg to get an accurate location for their desired dentist. Our project aims to promote easier dental care for the residents of Gothenburg.
